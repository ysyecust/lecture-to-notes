# 子代理规范：派发与汇总（> 30 分钟长课程）

**前置条件**：主代理已按 [`splitting.md`](./splitting.md) 完成通读、定大纲，并**委派 S1 子代理切好素材且已验收**，产出 `outline.md` +
`parts/transcript_part_XX.txt` + `parts/frames_part_XX/`。
本文件只讲**怎么派发、子代理怎么写、主代理怎么汇总**。

---

## 1. 派发方式

用 Agent 工具（`subagent_type: general-purpose`）派发。**并行派发**：在同一条消息里发起多个 Agent 调用，让它们同时跑。

> 说明：这里说的「并行」指在同一轮里发起多个 Agent 调用；是否真正并发由运行环境决定，本流程在两种情况下都成立，因为产物文件彼此隔离。

派发前对照 `splitting.md` 第 5 节的验收清单再确认一遍素材齐全。

---

## 2. 子代理 prompt 模板

把下面模板里的占位符全部替换成实际值，**不要留 `{...}` 未替换**：

```text
你是课堂笔记撰写子代理。任务：为一门长课程的第 {i}/{n} 个片段撰写中文 Markdown 笔记片段。

## 环境（所有路径读写一律用绝对路径）
- 工作目录：{outdir}
- 仓库根目录：{repo_root}

## 先读这两个文件再动笔
1. 写作规范：{repo_root}/skills/lecture-to-md/lecture-to-md/assets/notes-prompt.md
   —— 段落风格、标题层级、公式/代码格式、配图规则、最终检查清单，严格遵守。
2. 本片段大纲：{outdir}/outline.md 的「Part {i:02d}」一节，以及「全局统一约定」。

## 输入素材（只给这些，不要去翻别的目录）

### 1. 文字稿切片
{outdir}/parts/transcript_part_{i:02d}.txt
← 只写这一段的内容，严禁越界去写其他片段的知识点。
（若带时间戳：用它定位视频帧、标注「画面时间」，不要丢弃时间戳。）

### 2. 视频帧
{outdir}/parts/frames_part_{i:02d}/
← 已按本片段时段（{start_sec}–{end_sec} 秒）切好，目录内只有这几帧，**全部属于本片段**。
   逐帧真实时间查该目录下的 times.txt（格式：帧文件名<TAB>秒数）。
   用多模态能力查看候选帧后再决定用哪张。
   不要去读 {outdir}/frames/（那是全课程的帧，读了会配错图）。

### 3. 课件截图
{outdir}/slides/
← 本片段对应 **第 {slide_from}–{slide_to} 页**，文件名 slide-{slide_from:03d}.png … slide-{slide_to:03d}.png。
   按内容相关性挑选，不限时间。
   ⚠️ 该 PDF 是整门课合订本（共 {slide_total} 页），本课时只用到第 {deck_from}–{deck_to} 页。
   第 {deck_from} 页之前、第 {deck_to} 页之后的页面属于其他课时，一律不要使用。
   ⚠️ 标注页码时必须用 PDF 的真实页码（即文件名里的数字），不要按本片段重新编号。
（若课件就是本课时的，把这段改成「全部可用，共 {slide_total} 页」。）

## 本片段负责的一级标题（原样输出，不得改名 / 增删 / 调序）
1. {H1_title_1}
2. {H1_title_2}
（如有：3. {H1_title_3}）

若为长 H1 拆分任务，额外注明：本子代理只写 H1《{H1_title}》下的以下二级标题：{H2_list}。

## 上下文衔接（仅供理解起点，不要写进正文，也不要重复铺垫）
上一段结尾原文：
"""
{prev_tail_200chars}
"""
衔接提示：{transition_hint}

## 配图要求
- 按 notes-prompt.md 第七、八节：每个 `###` 下按需配图，**优先课件截图**，课件缺时用视频帧，**没有合适的图就不硬凑**。
- 选中的图复制到 {outdir}/assets/{title_name}/，文件名**一律以 p{i:02d}_ 开头**，例如 p{i:02d}_h3_01.png、p{i:02d}_h3_02a.png。
- 只创建该目录下的文件，不要修改或删除任何其他文件（其他子代理正在并行写入）。
- 正文引用相对路径：`![描述](assets/{title_name}/p{i:02d}_h3_01.png)`
- 视频帧图紧跟一行 `> 画面时间 HH:MM:SS`（时间查本片段的 times.txt）；
  课件截图紧跟一行 `> 课件第 N 页`（N = PDF 真实页码）。

## 输出
- 写入 {outdir}/parts/part_{i:02d}.md。文件内容只包含本片段的一级标题及其下级内容：
  - 不要加文件级大标题、不要写「本片段…」「以下是第 X 部分」这类元信息；
  - 不要写开场白和总结段——那是主代理汇总时统一处理的。
- 完成后返回 200 字以内的摘要，包含：
  1. 实际输出的一级标题列表；
  2. 字数；
  3. 插入的图片数量（分课件截图 / 视频帧），以及用到的课件页码；
  4. 存疑处、原文缺失处、或需要主代理在汇总时注意的衔接问题；
  5. 若发现给你的课件页码区间与文字稿内容对不上，明确指出（不要自行扩大页码范围）。
```

---

## 3. 主代理汇总

所有子代理返回后，主代理执行：

1. **校验完整性**：`parts/part_01.md` … `part_NN.md` 齐全；每个 part 的 H1 与 `outline.md` 一致（名字、数量、顺序）。
2. **顺序拼接**：按 01→NN 原序拼成 `{title_name}.md`，首行插入文档标题 `# <课程标题>`（与文件名对应；撰写子代理被禁止写文件级标题，这一步由主代理统一做）。
3. **衔接处去重**：相邻 part 因重叠切片产生的重复句/重复铺垫，删掉后一处，保留先出现的。
4. **统一风格**：按 `outline.md` 的「全局统一约定」扫一遍术语、代码语言标注、专有名词。
5. **图片校验**：
   - 正文里每个 `assets/{title_name}/xxx.png` 都真实存在；
   - 每帧图都有「画面时间」，且时间落在该 part 的区间内；
   - 每课件图都有页码，且页码落在 `outline.md` 标注的区间内（这是抓「用了别的课时的页」的关键一检）；
   - `pXX_` 前缀保留不动（它是并行隔离的凭据）。
6. **结构校验**：正文 H1 ≤ 10 个（首行文档标题不计入）且无重复；无五级/六级标题；无孤儿标题。
7. **清单自检**：按 `assets/notes-prompt.md` 第十一节逐条过。
8. 汇总完成后 `parts/` 保留（便于回溯重跑单个片段），不删除。
9. **接着进 Phase 6 结构重排**——见 [`structure-reorder.md`](./structure-reorder.md)。汇总出来的 H1 是「切分块」，未必等于「课程结构」，必须在交付前由主代理对照文字稿重排一次（只改标题行，不动正文）。

> ⚠️ 第 5 步的图片校验要在结构重排**之后**再跑一次。重排只动标题，理论上不影响配图；但如果重排时误删了标题行下方的图注、或误移了图片引用，这第二次校验能把问题拦在交付前。

### 单个片段失败时

不要整体重跑。只针对失败的 `part_XX` 重新派发一个子代理（沿用同一份 `transcript_part_XX.txt`、`frames_part_XX/` 与 prompt）。
已在 `assets/` 里的图不会冲突——重跑时新图会覆盖同前缀文件，这正是我们想要的。

### 子代理报告「课件页码对不上」时

说明切分时页码区间标错了。主代理自己翻一下课件修正 `outline.md` 里的页码，再把该 part 重派一次；不要放任子代理自行扩大范围（它一扩大就会撞上别的课时的页）。

## 4. 常见错误

| 错误                      | 后果                    | 正确做法                                    |
| ----------------------- | --------------------- | --------------------------------------- |
| 让子代理自己决定写哪几个 H1         | 标题重复、粒度不一、顺序错乱        | H1 由主代理在 outline 定死，子代理原样输出              |
| 把全量 `frames/` 丢给子代理     | 选到别的时段的帧，配图张冠李戴       | 只给 `parts/frames_part_XX/`，并明令禁止读全量目录   |
| 课件合订 PDF 不在 prompt 里限定页码 | 子代理用了别的课时的页           | prompt 里写死页码区间 + 合订本警告                  |
| 配图文件名不加 `pXX_` 前缀       | 并行写入互相覆盖，图片丢失         | 强制 `pXX_` 前缀隔离                          |
| 让子代理做跨片段整合/去重           | 内容被搬到错误位置             | 整合只在汇总阶段由主代理做                           |
| 汇总时不校验课件页码              | 错图流进最终稿，且很难肉眼发现       | 汇总第 5 步逐张核对页码是否落在 outline 区间内           |
| 子代理报告异常后直接采纳它的自行扩权      | 引入别的课时内容              | 由主代理核实并修正 outline，再重派该 part             |

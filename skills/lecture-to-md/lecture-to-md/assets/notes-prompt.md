# 课堂视频 / 录音稿整理任务提示词（优化版）

## 一、任务目标

我会发送一份教师课堂内容材料（录音稿、字幕稿、转写稿或分段材料）。请你将其整理成一份**完整、详细、可直接用于复习的课堂笔记**。

你的目标不是概括，而是尽可能还原老师的授课内容、逻辑、例子、拓展说明和问答过程，让我可以只靠这份笔记完成学习。整体风格是"详细课堂笔记"——既不是极简提纲，也不是逐句转写。

## 二、内容要求：完整保留，按序整理

### 1. 完整性

老师提到的所有内容都要尽量保留，包括但不限于：开场引入、背景说明、概念解释、公式推导、代码讲解、例子、类比、补充知识、课堂提醒、易错点、考试提示、学生提问与老师回答、临时展开的拓展内容。

不要为了缩短笔记而压缩内容：不要只写结论而省略讲解过程，不要删除看似"不重要"的引言、过渡和补充。只要老师讲到的、对理解课程有帮助的内容，都要写进笔记。

### 2. 顺序

严格按照老师讲课的原始顺序整理：

- 同一知识点在课程前、中、后多次出现时，不要合并，按当时讲到的位置分别整理；
- 不要把多个分散出现的知识点强行整合到一处；
- 如果老师按"直觉 → 正式定义 → 例子 → 注意事项"的顺序展开，笔记也必须按这个顺序展开。

小标题仅用于帮助阅读和组织内容，不能借划分标题打乱或重组老师的授课顺序。

## 三、学生提问与老师回答

材料中出现学生提问时必须保留，按原课堂顺序整理"学生问了什么、老师如何回答"，并用小标题标出。不要只写回答的结论，也不要把问答内容混入普通知识点中。格式示例：

````markdown
### 学生提问
（整理学生的问题，尽量保持原意。口语化的问题可适当改写为清楚的书面表达，但不得改变问题本身的含义。）

### 老师回答
（完整整理老师的回答，包括解释、举例、补充说明、推导过程和最终结论。）
````

## 四、可读性要求

笔记要适合初学者阅读：遇到抽象概念时用通俗语言解释清楚，让没有基础的人也能顺着老师的思路理解。

如果老师讲了某个结论，可以适当补充它的含义、用途、成立原因以及与前后内容的关系。但补充解释必须服务于理解，不能改变原始授课顺序，也不能替换老师讲过的内容。

## 五、段落与表达风格

- 笔记以自然段为主。同一个小主题下的背景、解释、例子和结论应合并到同一段中，读起来连贯自然；不要写成零散短句，也不要一句话单独成段。
- 每段围绕一个明确的小主题，一般控制在 **150 字左右**，内容复杂时可稍长，但尽量不超过 **220 字**。
- 项目符号只用于并列概念、步骤、分类、优缺点、条件、公式含义等内容，不要全文使用。
- 不要过度换行：连续相关的解释放在同一段，只有在话题转换、例子切换、进入新知识点、出现问答、公式或代码时才明显分段。

## 六、Markdown 格式要求

使用 Markdown 输出，标题按课堂内容自然划分，不过度拆碎也不过于粗略，层级要清楚：

- **第一行是文档标题** `# <课程标题>`（全文唯一，与输出文件名 `{title_name}.md` 对应）；它是全文第一个一级标题，**不计入**下面的数量限额；
- 正文一级标题不超过 10 个；课程时长 ≥60 分钟时至少 8 个；每个一级标题下的二级标题不超过 10 个；
- **每章最后一个二级标题必须是 `## 本章小结`**：回答本章提出的问题、并把读者交给下一章；不要只是复诵小节标题；
- **每章至少含一个**公式块 / 代码块 / 表格，**或两个判断框**（语法：`> **判断**：…`，独立成段）；每章正文 ≥ max(300, 0.7 × 全文字数 / 章数) 中文字；
- 讲到代码就要给代码块（不要只用散文转述）；对比 ≥3 种方案/格式要给表格；公式用 LaTeX；
- 三、四级标题数量不限；不使用五级、六级标题。

代码使用行间代码块，能判断语言时标注语言，无法判断则留空：

````markdown
```language
代码内容
```
````

公式使用 LaTeX：行内公式用 `$...$`，独立公式用 `$$...$$`。

笔记必须是纯 Markdown，不使用 `\section`、`\begin{...}`、`\includegraphics` 等 LaTeX 命令（数学公式的 `$...$` / `$$...$$` 除外）。

## 七、配图规则

- **先确认宿主能不能读图**（`read` 一张 PNG 试一次）。能读 → 必须用 contact sheet 看图挑图、并逐张核对图注；不能读 → 才用帧稳定性/边缘密度启发式，并在交付时说明。
- **配图优先级：课件截图 > 视频帧**；课件缺失时才用视频帧。
- 有对应画面时才配图，1~多张；**没有合适的图就不硬凑**。
- **图注必须描述画面里真实存在的东西**（幻灯片标题、代码片段、曲线），禁止凭小节标题编造；同一张幻灯片/同一段代码不得被两处重复引用。
- 视频帧**默认用整帧原图**（不裁不缩，老师/黑板/桌面都保留）；只有在用户要求或分栏必须放大文字时才裁一个面板，裁切同样只裁不缩，并在交付里说明。图片紧跟所属标题之后，再写正文。

## 八、图片引用语法

- 引用语法：`![图片描述](assets/{title_name}/xxx.png)`（相对路径，`{title_name}` 与输出文件名一致）。
- 视频帧图：紧接图下方用引用块标注来源时间 —— `> 画面时间 00:12:31`（或区间 `00:12:31–00:12:46`）。
- 课件截图：紧接图下方标注页码 —— `> 课件第 12 页`。

## 九、课件参考

- 课件里的文字、公式、图、表要**并入对应知识点**，不得遗漏；
- 课件内容与讲者顺序冲突时，以讲者讲授顺序为主线，把课件内容归并到对应位置；
- 课件里出现的、讲者未口头展开的要点，也应以「课件补充」形式保留，不丢弃。

## 十、特殊情况处理

### 1. 分段发送的长材料

- 每次只整理我当前发送的这一部分，并保持该部分内部的讲课顺序；
- 如果我说明"这是上一部分的继续"，请从上一部分的逻辑自然接续，不要重新开始总结整门课；
- 内容很长时优先保证完整性和顺序，可以分多个大标题继续整理，不要强行缩短或省略内容。

### 2. 转写稿不完整

原文有明显缺失、乱码、语义不完整或听不清的地方，先根据上下文尽量整理；确实无法判断的，标注：

> 【此处原文不完整，无法确定具体内容】

不得编造老师没有讲过的内容。

## 十一条附则：只写课上讲到的（禁止自造比喻、框架与公式）

这一条是硬要求，违者重写。笔记里允许出现的只有三类内容，且必须一眼分得清：

1. **老师讲到的**：机制、例子、数字、边界、警告、口头类比（例如「线程 = 人」「共享内存 = 物理世界」）——原样整理，可以改写成书面语。
2. **写作必需的组织件**：标题、章节顺序、每章的「本章小结」（复述本章讲到的机制并交棒下一章）、必要的一句话过渡。组织件不引入新观点。
3. **显式标注的补充**：教材里的通用事实（例如「C11 里这两个动作叫 acquire/release」）只有在确实帮读者时才写，并且**必须**写成 `> **补充（讲义整理）**…` 或在句内注明「教材通用的说法」；不标注就当作第 1 类，会被判违规。

**禁止**（都会被门禁 `[voice]` 抓出来）：

- 自己造的比喻：房间与钥匙、冰山、抽屉、排队买票之类的类比；
- 自己造的框架：把一讲切成「四个台阶/三层结构/五个层次」再拿它组织全文；
- 自己造的公式：把老师的口语结论硬写成 $S(n)=T(1)/T(n)$、改写为「不变式」之类；
- 「本质上是」「底层逻辑」「一句话总结」这类增味词——课上没这么说就别加。

判断标准很简单：**这句话老师说过吗？没说过，就只能是标注过的教材补充，否则删掉。**

## 十一、证据表与验收（与上游 PDF 流对齐）

写作**之前**先产出四份产物（格式与算法见 SKILL.md Phase 2.4），正文必须逐条兑现它们：

1. `lecture_profile.json`：模式（`technical-slide` / `mixed` / `conceptual-talk`）、目标读者、中心问题、读者读完能做什么、视觉原子数、公式原子数；
2. `teaching_atoms.tsv`：15–40 条教学原子，每条写清「哪个机制的哪句话」+ 证据（小节名、图名、时间）；
3. `numerical_claims.tsv`：老师提到的每个数字都要进正文（同样的数值、不改口径）；
4. `figure_manifest.tsv`：每张图对应哪一帧、哪段时间、什么主题。

交付前跑门禁，**必须 `OVERALL PASS`**：

```bash
python3 {skill_root}/scripts/verify_notes_md.py --workdir {outdir} --write-claims | tee {outdir}/verify_notes.txt
```

FAIL 就改被点名的项再重跑；`WARN`（如图数超上限）不阻塞，但要在交付里说明。

## 十二、最终检查清单

输出前请确认笔记满足以下全部条件：

1. 完整保留了老师讲过的内容，没有为求短而压缩；
2. 严格按照原始授课顺序，未合并分散出现的知识点；
3. 学生提问与老师回答单独标出且完整；
4. 段落连贯，单段一般不超过 220 字，项目符号使用克制；
5. 标题层级、代码块、LaTeX 公式格式符合第六部分的要求；
6. 缺失内容已规范标注，无自行编造的内容；
7. 每个该配图的小节都配了，优先课件截图，无合适图未硬凑；
8. 图片路径为相对路径 `assets/{title_name}/xxx.png`，视频帧有「画面时间」标注，课件截图有页码；
9. 课件文字、公式、图、表已并入对应知识点，无遗漏；
10. 每章都有 `## 本章小结`，且每章都有公式块/代码块/表格/两个判断框之一；
11. `teaching_atoms.tsv` 每条都是 `ok`，`numerical_claims.tsv` 每个数字都进了正文；
12. 图注经逐张看图核对（`vision: yes` 时），无同一画面重复引用；
13. `verify_notes_md.py` 输出末行为 `OVERALL PASS`。

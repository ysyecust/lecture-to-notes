How to contribute

按这五步提交

第一次使用 GitHub，也可以按下面的顺序完成。

  1. 01

    Fork 仓库

    点击上方按钮，在你的 GitHub 账号下创建 lecture-to-notes 副本。

  2. 02

    在自己的 Fork 中上传 PDF

    打开 content/inbox/，选择 Add file → Upload files。只上传小写扩展名的 .pdf 文件。

  3. 03

    保存 commit

    填写简短说明，例如 content: add CS336 lecture notes。这个 commit 只保存在你的 Fork 中。

  4. 04

    创建 Pull Request

    点击 Contribute → Open pull request，目标选择 ysyecust/lecture-to-notes:main，再填写 PDF 投稿模板。

  5. 05

    等待检查和审核

    系统会解析 PDF。维护者确认来源和内容后决定合并、要求修改或关闭 PR。

Before you submit

提交前检查

每个 PR 只添加 PDF，不要同时修改代码、课程目录或现有文件。

单个 PDF
≤ 25 MiB
每个 PR
≤ 10 个 PDF
合计大小
≤ 100 MiB

必须勾选

- [x] I have the right to share these PDFs for educational use.

请只提交你有权分享的资料。PR 模板还会询问课程、机构、学期、讲次、讲师和原始来源，方便维护者整理课程目录。

权限说明

谁能向仓库写入？

Commit 和 Pull Request 是两件事。贡献者在自己的仓库里保存 commit，再请求维护者合并。

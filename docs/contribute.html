你是仓库所有者，可以直接 commit。普通访客不能直接 push；除非你主动把某人添加为有写权限的协作者，否则他只能通过 Fork 和 PR 投稿。

网页操作

按这五步提交

第一次使用 GitHub，也可以按下面的顺序完成。

  1. 01

    Fork 仓库

    点击上方按钮，在你的 GitHub 账号下创建 lecture-to-notes 副本。

  2. 02

    在自己的 Fork 中上传 PDF

    打开 content/inbox/，选择 Add file → Upload files。只上传小写扩展名的 .pdf 文件。

  3. 03

    保存 commit

    填写简短说明，例如 content: add CS336 lecture notes。这个 commit 只保存在你的 Fork 中。

  4. 04

    创建 Pull Request

    点击 Contribute → Open pull request，目标选择 ysyecust/lecture-to-notes:main，再填写 PDF 投稿模板。

  5. 05

    等待检查和审核

    系统会解析 PDF。维护者确认来源和内容后决定合并、要求修改或关闭 PR。
